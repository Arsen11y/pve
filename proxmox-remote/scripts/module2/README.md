# Module 2

Модуль 2 намеренно не запускается одной кнопкой полностью.
Причины:
- RAID может стереть не те диски.
- Docker зависит от образов на Additional.iso.
- Samba DC зависит от корректных DNS/времени/hostname.
- Nginx proxy зависит от поднятых приложений и DNAT.

Добавляй задачи модуля 2 отдельными скриптами после проверки стенда.
